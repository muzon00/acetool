사용 안내

매일 하실 일

  1. POS에서 판매 내역 엑셀을 내려받습니다. (당일분 또는 이번 달 1일~오늘 누적분)
  2. 관리자 모드 › 업로드 › 파일 선택 › 미리보기의 기간과 합계 확인 › 등록
  3. "등록 완료 · 검산 일치"가 나오면 끝입니다. 홈 화면에서 달성률, 예상 마감금액을 확인합니다.
  • 같은 날짜를 다시 올리면 그 날짜의 기존 데이터가 새 내용으로 교체됩니다. 중복 합산되지 않습니다.
  • 파일에는 해당 날짜의 내판(일반)과 외판(B2B)이 모두 들어 있어야 합니다.

처음 한 번: 과거 데이터 올리기

  1. 목표·설정 탭에서 월 목표를 입력합니다.
  2. 업로드 탭에서 과거 데이터 CSV를 선택 › 미리보기의 전체 순매출이 원본 파일 합계와 같은지 확인 › 등록
  3. 이어서 10월 POS 판매 내역 엑셀을 올립니다.

과거 데이터 파일은 이 페이지(공개 저장소)에 넣지 않았습니다. 매출·거래처 정보가 인터넷에 공개되지 않도록 반드시 로그인 후 업로드로만 넣어 주세요.

POS 파일에 꼭 있어야 하는 열 이름

  • 필수: 영업일자, 구분, 과세결제금액, 비과세결제금액
  • 있으면 더 좋은 열: 담당자, 고객명, 대분류, 결제금액, 마진금액
  • 구분 값은 "일반"(내판)과 "B2B"(외판)만 인식합니다.
  • 순매출 = 과세결제금액 + 비과세결제금액 (VAT 별도, 반품/취소는 음수로 자동 차감)
  • 백업 CSV(일자, 구분, 담당자, 거래처, 대분류, 순매출, 마진) 형식도 그대로 다시 올릴 수 있습니다.

올리는 방법 두 가지 (모든 자료 공통)

  • 📱 문자 올리기(맨 위): 휴대폰에서 받은 문자를 붙여넣으면 바로 아래에 내용이 나오고 저장 버튼이 생깁니다.
  • 📄 파일 올리기: 종류를 고를 필요 없이 엑셀(.xlsx/.xlsb/.xls)·CSV·문자 .txt를 그냥 올립니다. 머리글을 보고 매출 / 시공 / 채권 / 본사 참고자료(일레포트·매출 유형별·PB 실적)를 알아서 구분합니다. 본사 일레포트(.xlsb)를 올리면 일산점 숫자가 매출현황과 1원까지 같은지 맞춰 봅니다.
  • 📁 올린 파일: 올린 파일 이름·올린 시간·올린 사람·자료 기간이 폴더처럼 쌓입니다. 파일명순·올린 시간순 정렬, 종류별로 골라 보기가 됩니다.
  • 📋 엑셀 표를 복사해서 붙여넣기: 파일 대신 엑셀에서 머리글 줄부터 표를 복사해 붙여넣고 "내용 확인"을 누릅니다.

월별 평가·원인

  • 달마다 목표 달성 · 전년 같은 달 대비 · 최근 흐름 대비 · 마진율로 점수(S~D 등급)를 매깁니다. 진행 중인 달은 예상 마감과 같은 기간끼리 비교합니다.
  • 원인 분석: 고른 달을 전월 / 전년 같은 달 / 직전 3개월 평균과 견줘, 매출이 늘고 준 까닭을 영업일 구성 · 내판 하루 매출력 · 외판 하루 매출력으로 나누고 대분류·담당자·거래처·마진·반품 변화를 짚어 줍니다.
  • 맨 아래 월별 평가표의 줄을 누르면 그 달로 바뀝니다.

월마감 체크

  • 매달 마감 때 꼭 확인할 일을 한 번 적어 두면, 모든 달에 같은 체크리스트가 생겨요. 항목 글자를 누르면 바로 고치고, ↑↓로 순서를 바꾸고, "한꺼번에 편집"에서 여러 줄을 한 번에 고칠 수 있어요.
  • 체크와 📝 메모는 달마다 따로 저장되고, 언제 누가 체크했는지 남아요. 이번 달 10일까지는 지난달 마감이 먼저 열려요.

판관비·BEP

  • 달을 고르고 그달 판관비 엑셀/CSV를 올리거나(첫 줄에 항목 · 금액 머리글) 직접 입력해 저장합니다. 합계·소계 줄은 빼고 항목만 더합니다.
  • 그달 마진(매출총이익)이 판관비보다 크면 BEP 달성입니다. BEP 매출 = 판관비 ÷ 마진율, 영업이익 = 마진 − 판관비로 계산하고, 미달이면 마진·매출이 얼마나 부족한지 보여 줍니다.
  • 마진은 상세 판매 내역(마진 열)에서 계산하므로, 그달 판매 내역을 올려야 계산됩니다. 진행 중인 달은 지금까지 기준과 예상 마감 기준을 함께 보여 줍니다.

욕실·시공 내역 (2025년, 2026년)

  1. 올릴 자료 › 시공 · 욕실 시공 내역을 고르고 파일이나 붙여넣기로 넣습니다. 연도별로 나눠 여러 번 올려도 됩니다.
  2. 여러 지점이 섞여 있으면 "저장할 지점"을 고릅니다. (일산이 기본)
  3. 같은 판매번호는 새 내용으로 교체되고, 여러 줄인 판매번호는 한 건으로 묶습니다.
  4. 목표·설정 › 시공 목표에서 월 목표 건수(기본 28건), 욕실만/전체, 영업일자/시공일자 기준을 정합니다.
  5. 시공 분석 탭에서 작년과 올해 월별 건수, 목표 대비 페이스, 품목·담당·판매원·구매경로별 현황을 봅니다.

비고·상담결과 같은 메모 칸과 배송·이동번호는 개인정보가 들어 있을 수 있어 저장하지 않습니다.

문자 (매출 마감 / PB브랜드 마감 / 일별 멤버쉽 현황, 매출 시간별)

  1. 휴대폰으로 접속해 받은 문자를 길게 눌러 복사합니다. (여러 개는 하나씩 이어 붙여도 됩니다)
  2. 업로드 탭 맨 위 📱 문자 올리기의 파란 버튼을 누르거나, 칸을 길게 눌러 붙여넣습니다. 종류는 자동으로 구분합니다.
  3. 바로 아래에 나온 내용을 확인하고 💾 저장하기
  • 매출(마감): 일산점 일마감·당월 금액, 건수, % 값과 함께 전 지점 값도 저장해 홈의 "지점 비교"와 "지점 순위"에 씁니다.
  • PB브랜드 마감: 일산점 PB 일매출·당월 금액, 전체 매출 중 PB 비중, % 값(마진율로 표시)과 전 지점 값을 저장해 홈의 "PB 브랜드"에 씁니다.
  • 일별 멤버쉽 현황: 일산 신규 가입, 누적 회원, VIP MASTER, MASTER, VIP+MASTER 판매건수(+ 전 지점 값)를 저장합니다.
  • 매출(시간별): 생각날 때 올리면 됩니다. 문자에 날짜가 없어 "시간별 문자의 날짜"에 적힌 날로 저장합니다.
  • 모든 금액(POS 순매출, 문자, 시공 실매출, 목표)은 부가세 별도 기준입니다. 문자 금액 기준은 목표·설정 탭에서 바꿀 수 있지만 기본값(VAT 별도)을 그대로 두면 됩니다.

직원에게 홈 화면 보여주기

  1. 매출 현황은 관리자 계정(이메일 + 숫자 6자리 비밀번호)으로만 들어올 수 있습니다. 홈 화면도 관리자만 볼 수 있습니다.
  2. 관리자 계정은 Firebase 콘솔 › Authentication에서 만들고, Firestore pos_roles에 그 UID로 role: "admin"을 넣어 줍니다.

보안 수칙

  • 관리자 모드는 20분 동안 사용이 없으면 자동으로 홈으로 돌아갑니다.
  • 관리자 페이지 주소는 acetool.site/pos/#admin 입니다. 새로고침해도 보던 탭(예: #admin/download)으로 다시 들어가고, 들어갈 때마다 관리자 권한을 서버에서 확인합니다.
  • 다운로드한 CSV/엑셀에는 거래처·마진 정보가 들어 있습니다. 공용 PC라면 사용 후 파일을 지우고 로그아웃해 주세요.
  • 퇴사자는 권한 관리 탭에서 바로 삭제해 주세요.

문제가 생기면

  • "검산 불일치"가 나오면 같은 파일을 다시 올려 주세요. (덮어쓰므로 안전합니다)
  • 엑셀(.xlsx)이 안 읽히면 엑셀에서 CSV(UTF-8)로 저장해서 올려 보세요. 엑셀 읽기 도구는 인터넷에서 불러옵니다.
  • "권한이 없습니다(permission-denied)"가 나오면 로그아웃 후 다시 로그인해 보세요.

제1조 목적

이 약관은 에이스 하드웨어 일산점 내부용 "매출 현황" 웹페이지(acetool.site/pos, 이하 "서비스")의 이용 조건을 정합니다.

제2조 이용 대상

서비스는 매장 관리자가 승인한 구글 계정으로 로그인한 사람만 이용할 수 있습니다. 권한은 "보기"와 "관리자" 두 가지이며, 관리자는 필요할 때 권한을 바꾸거나 삭제할 수 있습니다.

제3조 이용자의 의무

  • 서비스에서 본 매출·목표·거래처·담당자·마진 정보는 업무 목적으로만 사용하며, 외부(매장 밖 사람, 메신저 단체방, SNS 등)에 공유하지 않습니다.
  • 화면 캡처, 내려받은 CSV·엑셀 파일도 같은 기준으로 다루고, 공용 PC에서는 사용 후 파일을 지우고 로그아웃합니다.
  • 계정을 다른 사람과 함께 쓰거나, 권한 없는 정보에 접근하려고 시도하지 않습니다.

제4조 정보의 정확성

예상 마감금액, 달성률 등은 올라온 POS 자료와 문자 내용을 바탕으로 계산한 참고 값이며, 실제 정산·회계 기준 금액과 다를 수 있습니다. 중요한 결정은 원본 자료로 다시 확인해 주세요.

제5조 서비스의 변경·중단

운영상 필요하거나 보안 문제가 생기면 사전 안내 없이 기능을 바꾸거나 이용을 중단·제한할 수 있습니다.

제6조 권한 회수

퇴사, 부서 이동, 이 약관 위반 등의 경우 관리자는 즉시 권한을 삭제할 수 있습니다.

매출·마진 같은 숫자는 인쇄되지 않습니다. 파일 다운로드는 프린터가 연결된 다른 PC에서 열어(로그인 필요 없음) "인쇄"를 누르면 됩니다. 인쇄 창에서 "PDF로 저장"을 고르면 PDF로도 받을 수 있어요.

일정

    일정 추가

    홈 화면에 추가

    휴대폰 홈 화면(또는 PC 바탕화면)에 아이콘을 만들어 앱처럼 바로 열 수 있습니다.

    아이폰 · 아이패드 (Safari)

    • Safari로 acetool.site/pos 를 엽니다. (카카오톡 안에서 열렸다면 오른쪽 아래 메뉴 › "다른 브라우저로 열기")
    • 아래쪽 공유 버튼(네모에 위쪽 화살표) › 홈 화면에 추가 › 오른쪽 위 추가

    안드로이드 (크롬 · 삼성 인터넷)

    • 크롬: 오른쪽 위 ⋮ › 홈 화면에 추가 또는 앱 설치
    • 삼성 인터넷: 아래쪽 ≡ › 현재 페이지 추가 › 홈 화면

    PC (크롬 · 엣지)

    • 주소창 오른쪽의 설치 아이콘을 누르거나, 메뉴 › 앱 › 이 사이트를 앱으로 설치

    공용 PC에는 설치하지 마세요. 설치해도 로그인은 그대로 필요합니다.

    개인정보처리방침

    시행일: 2026년 10월 24일

    1. 처리하는 개인정보와 목적

    • 로그인한 이용자 · 구글 계정 이메일, 이름(표시 이름), 구글이 부여한 사용자 ID(UID) — 본인 확인과 권한(보기/관리자) 관리, 승인 요청 처리에만 씁니다.
    • 업무 자료 · 관리자가 올린 판매 내역에 들어 있는 외판 담당자 이름, 거래처명(개인 고객 이름이 포함될 수 있음), 매출·마진 금액 — 매장 매출 관리 목적으로만 쓰며 관리자만 볼 수 있습니다.
    • 등록 이력 · 자료를 올린 관리자 이메일과 시각 — 검산과 사고 추적용입니다.
    • 접속 수 · 날짜별 접속 횟수 합계만 저장하며, 누가 접속했는지는 기록하지 않습니다.

    2. 보관 위치와 접근 통제

    • 정보는 Google LLC가 제공하는 Firebase(Cloud Firestore, Firebase Authentication)에 저장됩니다.
    • 보안 규칙으로 승인된 계정만 읽을 수 있고, 거래처·담당자·마진 등 상세 자료와 권한 목록은 관리자만 읽을 수 있습니다.
    • 이 기기의 브라우저에는 화면 설정(글씨·디자인)과 오늘 접속을 이미 셌는지 여부만 저장되며, 매출 자료는 저장되지 않습니다.

    3. 보유 기간과 파기

    • 권한 정보는 권한이 삭제될 때(퇴사 등) 함께 지웁니다. 거절된 승인 요청은 바로 지웁니다.
    • 업무 자료는 매장 운영에 필요한 기간 동안 보관하며, 필요가 없어지면 관리자가 삭제합니다.

    4. 제3자 제공

    개인정보를 다른 사람이나 회사에 제공하거나 판매하지 않습니다. 저장·로그인 처리를 위해 Google Firebase를 이용합니다.

    5. 이용자의 권리

    본인 정보의 확인, 수정, 삭제(권한 해지)를 매장 관리자에게 요청할 수 있으며, 지체 없이 처리합니다.

    6. 문의

    개인정보 관련 문의는 에이스 하드웨어 일산점 매장 관리자에게 해 주세요.
