판매 내역 올리기

POS에서 내려받은 판매 내역 엑셀(.xlsx)이나 CSV를 올리세요. 파일에 들어 있는 날짜의 기존 데이터는 새 파일 내용으로 교체되므로, 같은 날짜를 다시 올려도 중복되지 않습니다. 파일에는 해당 날짜의 내판(일반)과 외판(B2B)이 모두 들어 있어야 합니다.

여기를 눌러 파일을 선택하거나 끌어다 놓으세요
.xlsx · .xls · .csv (최대 30MB)

문자 붙여넣기 (일산점만 저장)

시간별 매출, 일마감, 멤버쉽 현황 문자를 한꺼번에 붙여넣으세요. 세 종류가 섞여 있어도 자동으로 구분하고, 일산점 항목만 저장합니다. 같은 날짜·시각의 기존 값은 새 값으로 교체됩니다.

시간별 문자(“ACE홈센터 - 11시”)에는 날짜가 없습니다. 붙여넣은 첫 시간별 문자의 날짜를 정해 주세요. 시각이 줄어들면(예: 21시 다음 9시) 다음 날로 계산하고, 마감 문자 뒤에 오는 시간별 문자는 다음 날로 계산합니다.

월 목표 등록

문자 금액 기준

시간별·마감 문자의 금액이 VAT 포함인지 별도인지 선택하세요. 상세 분석의 "마감 문자와 POS 대조" 표에서 차이가 거의 0으로 나오는 쪽이 맞는 선택입니다.

휴무일

영업하지 않는 날을 한 줄에 하나씩 YYYY-MM-DD 형식으로 적으세요. 남은 영업일 계산과 누락일 점검에서 제외됩니다.

사용 안내

매일 하실 일

  1. POS에서 판매 내역 엑셀을 내려받습니다. (당일분 또는 이번 달 1일~오늘 누적분)
  2. 관리자 모드 › 업로드 › 파일 선택 › 미리보기의 기간과 합계 확인 › 등록
  3. "등록 완료 · 검산 일치"가 나오면 끝입니다. 홈 화면에서 달성률, 예상 마감금액을 확인합니다.
  • 같은 날짜를 다시 올리면 그 날짜의 기존 데이터가 새 내용으로 교체됩니다. 중복 합산되지 않습니다.
  • 파일에는 해당 날짜의 내판(일반)과 외판(B2B)이 모두 들어 있어야 합니다.

처음 한 번: 과거 데이터 올리기

  1. 목표·설정 탭에서 월 목표를 입력합니다.
  2. 업로드 탭에서 과거 데이터 CSV를 선택 › 미리보기의 전체 순매출이 원본 파일 합계와 같은지 확인 › 등록
  3. 이어서 10월 POS 판매 내역 엑셀을 올립니다.

과거 데이터 파일은 이 페이지(공개 저장소)에 넣지 않았습니다. 매출·거래처 정보가 인터넷에 공개되지 않도록 반드시 로그인 후 업로드로만 넣어 주세요.

POS 파일에 꼭 있어야 하는 열 이름

  • 필수: 영업일자, 구분, 과세결제금액, 비과세결제금액
  • 있으면 더 좋은 열: 담당자, 고객명, 대분류, 결제금액, 마진금액
  • 구분 값은 "일반"(내판)과 "B2B"(외판)만 인식합니다.
  • 순매출 = 과세결제금액 + 비과세결제금액 (VAT 별도, 반품/취소는 음수로 자동 차감)
  • 백업 CSV(일자, 구분, 담당자, 거래처, 대분류, 순매출, 마진) 형식도 그대로 다시 올릴 수 있습니다.

문자(시간별/마감/멤버쉽) 붙여넣기 - 일산점만 저장

  1. 아이폰 문자를 맥북으로 가져옵니다. (설정 › 메시지 › 문자 메시지 전달에서 맥북 켜기 → 맥북 메시지 앱에서 대화 선택 후 Cmd+A, Cmd+C)
  2. 업로드 탭 아래 "문자 붙여넣기" 칸에 붙여넣습니다. 시간별 / 마감 / 멤버쉽 문자가 섞여 있어도 자동으로 구분합니다.
  3. "시간별 문자의 첫 날짜"를 확인하고 "내용 확인" › 표가 맞으면 "저장"
  • 시간별 문자: 일산점 금액과 건수를 "그 시각까지의 당일 누적"으로 저장합니다.
  • 마감 문자: 일마감과 당월매출의 일산점 금액, 건수, % 값을 저장합니다.
  • 멤버쉽 문자: 일산 신규 가입, 누적 회원, VIP MASTER, MASTER, VIP+MASTER 판매건수를 저장합니다.
  • 문자 금액이 VAT 포함인지 별도인지는 목표·설정 탭에서 고릅니다. POS 대조표에서 "일치"가 나오면 맞는 선택입니다.

직원에게 홈 화면 보여주기

  1. 직원이 acetool.site/pos 에서 본인 구글 계정으로 로그인합니다. ("승인 대기 중" 화면이 나옵니다)
  2. 권한 관리 탭에서 요청을 확인하고 "보기 권한"으로 승인합니다.
  3. 직원(보기 권한)은 홈 화면만 볼 수 있습니다. 담당자·거래처·마진 정보와 업로드·다운로드는 관리자만 가능합니다. (서버 규칙으로 막혀 있어 화면을 조작해도 볼 수 없습니다)

보안 수칙

  • 관리자 모드는 20분 동안 사용이 없으면 자동으로 홈으로 돌아갑니다.
  • 다운로드한 CSV/엑셀에는 거래처·마진 정보가 들어 있습니다. 공용 PC라면 사용 후 파일을 지우고 로그아웃해 주세요.
  • 퇴사자는 권한 관리 탭에서 바로 삭제해 주세요.

문제가 생기면

  • "검산 불일치"가 나오면 같은 파일을 다시 올려 주세요. (덮어쓰므로 안전합니다)
  • 엑셀(.xlsx)이 안 읽히면 엑셀에서 CSV(UTF-8)로 저장해서 올려 보세요. 엑셀 읽기 도구는 인터넷에서 불러옵니다.
  • "권한이 없습니다(permission-denied)"가 나오면 로그아웃 후 다시 로그인해 보세요.

이용약관

시행일: 2026년 10월 24일

제1조 목적

이 약관은 에이스 하드웨어 일산점 내부용 "매출 현황" 웹페이지(acetool.site/pos, 이하 "서비스")의 이용 조건을 정합니다.

제2조 이용 대상

서비스는 매장 관리자가 승인한 구글 계정으로 로그인한 사람만 이용할 수 있습니다. 권한은 "보기"와 "관리자" 두 가지이며, 관리자는 필요할 때 권한을 바꾸거나 삭제할 수 있습니다.

제3조 이용자의 의무

  • 서비스에서 본 매출·목표·거래처·담당자·마진 정보는 업무 목적으로만 사용하며, 외부(매장 밖 사람, 메신저 단체방, SNS 등)에 공유하지 않습니다.
  • 화면 캡처, 내려받은 CSV·엑셀 파일도 같은 기준으로 다루고, 공용 PC에서는 사용 후 파일을 지우고 로그아웃합니다.
  • 계정을 다른 사람과 함께 쓰거나, 권한 없는 정보에 접근하려고 시도하지 않습니다.

제4조 정보의 정확성

예상 마감금액, 달성률 등은 올라온 POS 자료와 문자 내용을 바탕으로 계산한 참고 값이며, 실제 정산·회계 기준 금액과 다를 수 있습니다. 중요한 결정은 원본 자료로 다시 확인해 주세요.

제5조 서비스의 변경·중단

운영상 필요하거나 보안 문제가 생기면 사전 안내 없이 기능을 바꾸거나 이용을 중단·제한할 수 있습니다.

제6조 권한 회수

퇴사, 부서 이동, 이 약관 위반 등의 경우 관리자는 즉시 권한을 삭제할 수 있습니다.

홈 화면에 추가

휴대폰 홈 화면(또는 PC 바탕화면)에 아이콘을 만들어 앱처럼 바로 열 수 있습니다.

아이폰 · 아이패드 (Safari)

  • Safari로 acetool.site/pos 를 엽니다. (카카오톡 안에서 열렸다면 오른쪽 아래 메뉴 › "다른 브라우저로 열기")
  • 아래쪽 공유 버튼(네모에 위쪽 화살표) › 홈 화면에 추가 › 오른쪽 위 추가

안드로이드 (크롬 · 삼성 인터넷)

  • 크롬: 오른쪽 위 ⋮ › 홈 화면에 추가 또는 앱 설치
  • 삼성 인터넷: 아래쪽 ≡ › 현재 페이지 추가 › 홈 화면

PC (크롬 · 엣지)

  • 주소창 오른쪽의 설치 아이콘을 누르거나, 메뉴 › 앱 › 이 사이트를 앱으로 설치

공용 PC에는 설치하지 마세요. 설치해도 로그인은 그대로 필요합니다.

개인정보처리방침

시행일: 2026년 10월 24일

1. 처리하는 개인정보와 목적

  • 로그인한 이용자 · 구글 계정 이메일, 이름(표시 이름), 구글이 부여한 사용자 ID(UID) — 본인 확인과 권한(보기/관리자) 관리, 승인 요청 처리에만 씁니다.
  • 업무 자료 · 관리자가 올린 판매 내역에 들어 있는 외판 담당자 이름, 거래처명(개인 고객 이름이 포함될 수 있음), 매출·마진 금액 — 매장 매출 관리 목적으로만 쓰며 관리자만 볼 수 있습니다.
  • 등록 이력 · 자료를 올린 관리자 이메일과 시각 — 검산과 사고 추적용입니다.
  • 접속 수 · 날짜별 접속 횟수 합계만 저장하며, 누가 접속했는지는 기록하지 않습니다.

2. 보관 위치와 접근 통제

  • 정보는 Google LLC가 제공하는 Firebase(Cloud Firestore, Firebase Authentication)에 저장됩니다.
  • 보안 규칙으로 승인된 계정만 읽을 수 있고, 거래처·담당자·마진 등 상세 자료와 권한 목록은 관리자만 읽을 수 있습니다.
  • 이 기기의 브라우저에는 화면 설정(글씨·디자인)과 오늘 접속을 이미 셌는지 여부만 저장되며, 매출 자료는 저장되지 않습니다.

3. 보유 기간과 파기

  • 권한 정보는 권한이 삭제될 때(퇴사 등) 함께 지웁니다. 거절된 승인 요청은 바로 지웁니다.
  • 업무 자료는 매장 운영에 필요한 기간 동안 보관하며, 필요가 없어지면 관리자가 삭제합니다.

4. 제3자 제공

개인정보를 다른 사람이나 회사에 제공하거나 판매하지 않습니다. 저장·로그인 처리를 위해 Google Firebase를 이용합니다.

5. 이용자의 권리

본인 정보의 확인, 수정, 삭제(권한 해지)를 매장 관리자에게 요청할 수 있으며, 지체 없이 처리합니다.

6. 문의

개인정보 관련 문의는 에이스 하드웨어 일산점 매장 관리자에게 해 주세요.
